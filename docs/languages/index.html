Canonical specification

Versions

Each folder is a version of the specification. A file in a folder replaces the same file from the parent. When a file is missing, the build uses the parent file. Folder names are yours: a language, an audience, a reading level, or any other hierarchy.

A .md or .manual.md file was written by a person and is never replaced by an AI rewrite. An AI rewrite is stored as .ai.md. If a manual file is in the same folder, the manual file is the one that is published.
